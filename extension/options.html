Dev Academy Diary settings

1. Create a GitHub token

The token lets this extension save files to your diary repo, and nothing else.

  1. Open GitHub's new token page.
  2. Name it Dev Academy Diary and choose an expiry date.
  3. Under Repository access, choose Only select repositories and pick your diary repo.
  4. Under Permissions, set Contents to Read and write.
  5. Click Generate token and copy it.

2. Connect your diary

Your token is stored only in this browser.
